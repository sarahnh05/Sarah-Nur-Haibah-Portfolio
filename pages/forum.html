Forum Disscussion App

A discussion forum web application built with React and Redux Toolkit as part of Dicoding's Intermediate React course.


Features

  • User Authentication — Allows users to log in and access the application.
  • Thread Creation — Enables users to create discussion threads.
  • Comments — Allows users to participate in discussions by commenting on threads.
  • Voting — Enables users to vote on discussion threads.

Tech Stack

  • React
  • Redux Toolkit
  • React Router
  • Jest
  • Cypress
  • Storybook

Key Implementations

  • Managed application state using Redux Toolkit.
  • Implemented client-side navigation using React Router.
  • Developed interactive discussion features, including thread creation, comments, and voting.
  • Tested application functionality using Jest and Cypress.

Learning Outcomes

This project provided hands on experience in building a React application, managing global state, implementing interactive features, and testing application functionality.
