Notes App

A note taking web application built with React, featuring user authentication, note management, and interface customization.


Features

  • User Authentication — Allows users to log in and access the application.
  • Create Notes — Enables users to create and save notes.
  • Delete Notes — Allows users to remove notes they no longer need.
  • Archive Notes — Enables users to archive notes for better organization.
  • Theme Customization — Allows users to switch between available interface themes.
  • Language Settings — Supports switching the application language.

Tech Stack

  • React
  • React Router
  • Context API
  • CSS
  • Vite

Key Implementations

  • Managed application state using Context API.
  • Implemented client-side navigation using React Router.
  • Integrated REST APIs to support authentication and note management.
  • Developed theme and language settings to provide a more personalized user experience.

Learning Outcomes

Gained hands-on experience in building a React application, managing shared state, integrating REST APIs, and implementing user-facing features with customizable interface settings.
